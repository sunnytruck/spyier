# 強化プレビューと文字の読みやすさ

## 強化の操作

休憩所のカード一覧には「強化後を表示」チェックボックスがある。初期状態はOFFで、選択前から全候補のカード名・コスト・効果・特性をまとめて切り替えられる。表示用コピーだけを強化済みにするため、元のカード・HP・ゴールド・乱数は変更しない。

未強化カードの「強化内容を確認」を押すと、現在のカードを表示する。「強化後を表示」で名前・コスト・効果・特性を切り替え、変更箇所を色と下線で示す。確認後に「強化を確定する」を押した場合だけ、既存の強化アクションを実行する。戻る・閉じる・表示切替ではゲーム状態を変更しない。一覧の表示設定は確認画面を閉じても維持する。

強化済みカードは対象に含めない。今回のカードはすべて1段階強化の既存仕様を維持している。

ランダム強化イベントは選択肢を押した時点で、既存のシード付き抽選と強化を一度だけ確定する。事前確認は行わない。強化済みのカードと効果、実際のHP・ゴールドの変動は専用の結果画面に表示し、結果の状態ごと保存する。結果画面には次へ進む操作だけがあり、再読み込みで対象を再抽選しない。カード獲得・削除、レリック、ポーション、特別戦闘の結果も同じ画面で確認できる。

デッキ・報酬・ショップ・図鑑のカードでも強化前後を切り替えられる。表示が強化後でも、購入・取得するカードを勝手に強化しない。演出用の札にはプレビュー操作ボタンを付けない。

## 表示の根拠

- `src/presentation/cardUpgrade.ts` が既存の `CardDefinition` から表示モデルを作る。
- 通常/強化の名前、コスト、説明、効果配列、廃棄・保留・エセリアル・天賦を参照する。Xコストは数値へ置き換えない。
- 説明文を推測・要約・生成しない。差分表示も原文の文字列をそのまま保ち、数値や追加された文言に印を付ける。
- `CardUpgradePreview` と `CardUpgradeToggle` を強化確認画面とカード詳細で共有する。プレビュー状態はUI内だけに持ち、保存形式に追加しない。
- イベント結果に表示するカードは、確定したreducerの変更後のカードをそのまま参照する。UIは抽選や効果処理を行わない。

## 文字とレイアウト

`src/styles/readability.css` を既存スタイルの後に読み込む。日本語ゴシック体のローカルフォントを優先し、フォント配信への外部接続は追加していない。大きなタイトルや世界観の見出しは従来の装飾書体を残す。

本文は15px、詳細カード効果は14px、戦闘中のカード効果は13pxを基準に、重要度で大きさを分ける。補助ラベルは小さめのまま、色・行間を調整する。ボタン・選択肢は折り返しと押しやすい余白を持つ。使用できないカードや選択肢も、本文まで薄く消さず境界・色で状態を示す。

長いカード名・効果文に応じて札の高さを広げる。小画面では縦スクロールや手札の横スクロールを使い、情報を切り取らない。複数敵の長い予告と状態表示が重ならないよう、狭い画面では自然な文書配置を使う。

## 互換性と検証

5職業、演出イベント、保存キー・バージョンを維持する。休憩所の確認途中で再読み込みすると未確定の確認画面だけが閉じ、保存済みのカード選択から再開する。イベントの結果は確定済みなので、再読み込み後も同じ結果から再開する。

コスト低下、数値変更、Xコスト、保留追加、廃棄解除を検証する。休憩所の一覧切り替え、取消、確定前後の保存内容を確認する。イベントの結果画面・再読み込み・次へ進む操作で、確定済みの強化や報酬が重複しないことを確認する。ブラウザでは5職業、PC/スマートフォン幅、長い文章、全候補の一括切り替え・個別確認・取消・確定を確認する。
