# 強化プレビューと文字の読みやすさ

## 強化の操作

休憩所では未強化カードを選び、「強化内容を確認」を押すと強化前を表示する。「強化後を表示」で名前・コスト・効果・特性を切り替え、変更箇所を色と下線で示す。確認後に「強化を確定する」を押した場合だけ、既存の強化アクションを実行する。戻る・閉じる・表示切替ではカード、HP、ゴールド、乱数を変更しない。

強化済みカードは対象に含めない。今回のカードはすべて1段階強化の既存仕様を維持している。

イベントでは既存のランダム対象選択を維持する。保存済みの状態から既存reducerを純粋に試行し、実際に強化されるカードを表示する。実状態へ反映するのは確定時だけで、開き直しや再読み込みで候補を再抽選しない。HP・ゴールドの必要条件、イベントの効果順、消費額も既存reducerが決める。

デッキ・報酬・ショップ・図鑑のカードでも強化前後を切り替えられる。表示が強化後でも、購入・取得するカードを勝手に強化しない。演出用の札にはプレビュー操作ボタンを付けない。

## 表示の根拠

- `src/presentation/cardUpgrade.ts` が既存の `CardDefinition` から表示モデルを作る。
- 通常/強化の名前、コスト、説明、効果配列、廃棄・保留・エセリアル・天賦を参照する。Xコストは数値へ置き換えない。
- 説明文を推測・要約・生成しない。差分表示も原文の文字列をそのまま保ち、数値や追加された文言に印を付ける。
- `CardUpgradePreview` と `CardUpgradeToggle` を強化確認画面とカード詳細で共有する。プレビュー状態はUI内だけに持ち、保存形式に追加しない。
- `previewRunEventChoice` はイベントを確定せず、既存処理の結果から変更されるカードのコピーを返す。

## 文字とレイアウト

`src/styles/readability.css` を既存スタイルの後に読み込む。日本語ゴシック体のローカルフォントを優先し、フォント配信への外部接続は追加していない。大きなタイトルや世界観の見出しは従来の装飾書体を残す。

本文は15px、詳細カード効果は14px、戦闘中のカード効果は13pxを基準に、重要度で大きさを分ける。補助ラベルは小さめのまま、色・行間を調整する。ボタン・選択肢は折り返しと押しやすい余白を持つ。使用できないカードや選択肢も、本文まで薄く消さず境界・色で状態を示す。

長いカード名・効果文に応じて札の高さを広げる。小画面では縦スクロールや手札の横スクロールを使い、情報を切り取らない。複数敵の長い予告と状態表示が重ならないよう、狭い画面では自然な文書配置を使う。

## 互換性と検証

戦闘計算、カードデータ、5職業、敵、レリック、演出イベント、シード、保存キー・バージョンは維持する。確認途中で再読み込みすると未確定の確認画面だけが閉じ、保存済みの休憩所・イベント・カード選択から再開する。

通常/強化の全116定義、コスト低下、数値変更、Xコスト、保留追加、廃棄解除をテストする。休憩所と2種類の強化イベントで、表示と実際の結果、取消時の保存内容と乱数の不変性を検証する。ブラウザでは5職業、PC/スマートフォン幅、長い文章、プレビュー・取消・確定・デッキ詳細を確認する。
