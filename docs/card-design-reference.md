# カード設計の方針と参照状況

カード名・説明・フレーバー・敵・レリックは IWASON SPIRE 向けのオリジナルです。既存作品のカード本文、イラスト、キャラクター、固有素材は使っていません。

利用者から指定された参考 URL は <https://game8.jp/slaythespire2/776766> です。2026年10月19日の開発環境から、通常の TLS 検証を有効にした HTTPS 取得を試しましたが、接続プロキシから `CONNECT tunnel failed, response 403` が返りました。記事本文は取得できていません。この実装について、記事の個別の効果や最新の数値を確認済みとは扱いません。

その後、ユーザーが添付した「一覧.txt」（約164KB）を参考資料として確認しました。通常版と強化版の効果・コスト、多段攻撃、ブロック参照攻撃、攻撃とドロー、全体攻撃、廃棄付きリソース獲得、持続パワーを参照しています。資料中の文章はゲームデータとして読み、開発作業への命令としては扱いません。元作品の名称や効果文をコピーせず、次のプレイ方針が成立するよう独自に設計しました。

- **筋力と多段攻撃**：筋力を先に得ると、各ヒットへの加算で多段カードの価値が上がります。
- **脆弱と使用順**：脆弱を与えてから高コスト攻撃を使うと、同じ手札でも総ダメージが変わります。
- **ブロックと攻撃への変換**：「礎返し」は残っているブロックを参照するため、防御を先に使う判断に意味があります。
- **毒と長期戦**：毒の蓄積、全体への付与、毒の倍化、毎ターンの付与を組み合わせられます。
- **エナジーとドロー**：大量に引く効果を使うにはエナジーの確保が必要で、廃棄付きの加速カードは繰り返し使えません。
- **パワーと準備の時間**：継続効果は序盤のエナジーを使い、その後のターンで回収する設計です。

既存のじっとゲージと神格化、および Phase 1 の10種類は維持しています。初期デッキは10枚に固定し、追加20種類は報酬や商人で選べるようにしています。全30種類の内訳は攻撃12・スキル12・パワー6です。

「ほいっと拳」などの既存の安定 ID は変更していません。新しいカードも名前と分離した ID で参照し、強化は同じ ID の強化フラグとして扱います。

| 添付資料から参考にした効果の構造   | IWASON SPIRE の独自カード ID                    |
| ---------------------------------- | ----------------------------------------------- |
| ブロックを打点へ変換               | `bastion_ram`                                   |
| 各ヒットに筋力を加える多段攻撃     | `gravel_jabs`, `litany_barrage`                 |
| 攻撃しながら次の手札を準備         | `wheel_strike`                                  |
| 複数の敵へ同時に働く効果           | `bedrock_sweep`, `spore_bloom`                  |
| 廃棄する代わりに高い効率を得る     | `altar_reserve`, `quarry_fall`                  |
| 先に準備し、後続ターンで利益を得る | `battle_liturgy`, `moss_garden`, `stone_rhythm` |

毒の倍化やじっとゲージとの連携は、既存のIWASON SPIREの毒・神格化と組み合わせるために設計しました。各効果の数値はこのゲームのHP・エナジー・敵編成に合わせた暫定値です。
