# 戦闘コンパクトUIのブラウザ検証

## 再現手順

検証用のブラウザにはPython PlaywrightとChromiumを使う。依存パッケージをゲーム本体へ追加せず、既存のVite開発サーバーまたは本番ビルドのプレビューへ接続する。

```bash
npx esbuild scripts/browser/compact-battle-fixtures.ts --bundle --platform=node --format=esm --outfile=/tmp/spyier-compact-fixtures.mjs
node /tmp/spyier-compact-fixtures.mjs /tmp/spyier-compact-fixtures.json
npm run build
npm run preview -- --port 5283
```

別のターミナルから実行する。ブラウザは独立した一時コンテキストを使い、開発者が利用中のブラウザのセーブには触れない。

```bash
IWASON_BROWSER_URL=http://127.0.0.1:5283/spyier/ python scripts/browser/check-compact-battle.py
IWASON_BROWSER_URL=http://127.0.0.1:5283/spyier/ IWASON_BROWSER_DRAG_ONLY=1 python scripts/browser/check-compact-battle.py
COMPACT_BATTLE_URL=http://127.0.0.1:5283/spyier/ python scripts/browser/check-hand-details.py
```

`QA_WIDTH=1920`・`1366`・`390`で独立した画面幅だけを実行できる。`IWASON_BROWSER_OUTPUT`で画面画像とJSON結果の保存先を指定できる。

## 検証の範囲

- 5職業 × 単体敵／3体の敵／15枚の手札 × 1920×1080・1366×768・390×844の45組。
- 敵HP・行動予告、プレイヤーHP・状態、5職業HUD、エナジー、終了、3種類の山札、手札を矩形と画面画像で確認する。`overflow:hidden`だけで隠して合格とせず、実キャラクターSVGや操作部品の位置も検査する。
- オーブ6枠、毒・破滅、星と当ターン星・鍛造、召喚HP、筋力、敏捷・活力・プレートを現在の保存値と照合する。
- 全文カード詳細、敵詳細、固有リソース詳細、各オーブの詳細、岩霊、レリック一覧、山札・捨て札・廃棄札を開き、確認操作で保存が変わらないことを検査する。
- カード3枚の使用とターン終了を画面から操作し、エンジンで同じ操作をした保存本文と完全一致すること、再読込後も一致することを確認する。
- 大量手札、画面端の拡大詳細、状態説明、カードの使用禁止、タッチ確認、横スワイプ、ドラッグの有効／無効対象、別の敵への攻撃、ポーション、連打防止、速度変更、演出スキップ・軽減を確認する。

カード・敵・リソースのストレス配置は、現在のエンジンで生成した戦闘を検証用に整えたもの。保存検証を通したうえで使用するが、自然なプレイでそのデッキやHPへ到達したこと、攻略バランス、勝率、60fpsを証明するものではない。合法な通しプレイと旧セーブの回帰検証は別のテストで行う。

## 最終結果

2026-10-20、固定した本番ビルド（`index-C3o8Dbgp.js` / `index-BRiTQOSx.css`）を `/spyier/` で実行し、以下が成功した。開発サーバーの再起動で中断された実行や、レリック一覧の見出しを誤って仮定して失敗した検査は最終合格に含めていない。後者は保存済みの所持IDと表示アイコンの全件比較へ修正し、同じ本番成果物で再実行した。

| 検証 | 結果 |
| --- | --- |
| 1920×1080：5職業×単体・3体・15枚手札 | 15/15成功 |
| 1366×768：同上 | 15/15成功 |
| 390×844：同上、タッチで確認・使用 | 15/15成功 |
| ドラッグ、無効対象、別の敵への攻撃、ポーション、連打制御、スキップ、速度・演出軽減 | 3画面幅×5職業の15/15成功 |
| 50枚手札の末尾詳細、使用不能カードの確認・使用禁止 | 5/5成功 |

45組では合計180回のカード使用・ターン終了を操作し、各操作後と再読み込み後の保存本文がエンジンの計算結果と一致した。すべての最終実行でJavaScript例外0件。追加の15組でも設定・演出スキップが戦闘結果を変えず、1回の操作が1回だけ確定することを検証した。

別途375×667で全5職業の3体・長い行動予告・15枚手札・状態異常・6枠オーブを表示検査し、ページ全体のスクロールや操作バーへの重なりがないことを確認した。この小画面の検査は上の45組の全操作検証とは区別する。

最終結果JSONは実行環境の `/tmp/spyier-production-final-{1920,1366,390}/results.json`、`/tmp/spyier-production-drag/results.json`。50枚手札の結果は `/tmp/spyier-production-hand-details.log`。一時出力はゲームへ同梱せず、上記のリポジトリ内スクリプトで再生成できる。
