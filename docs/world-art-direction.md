# 世界の原画と差し替え境界

今回の舞台は「古代岩石信仰 × 深緑の闇 × じっと教」。既存の岩尊けいとの多面体の顔、石の体、肩・胸の刻印をそのまま生かす。背景は手前の大きな岩、奥へ細くなる柱列、暗い聖堂、広がる石床、上から落ちる光という前後関係で構成し、人物とライブ情報のための静かな場所を残す。余白に説明や装飾を詰めない。

## 原画

すべてIWASON SPIRE向けに制作したオリジナルSVGで、外部ゲームの画像・UI・紋章・文章を使っていない。ダウンロードや外部フォントなしで表示する。

| 画面 | 素材 | 構図 |
| --- | --- | --- |
| 戦闘 | `battle-sanctuary.svg` | 視線の集まる奥の聖堂、前後の柱、傷のある石床。ライブキャラクターを前景へ置く |
| タイトル | `title-pilgrimage.svg` | 壊れた大門の向こうの塔と階段。左のメニューと右の岩尊を主役にする |
| 祝福 | `ritual-stone-circle.svg` | 岩の祭壇と独自の石輪・メンヒル印。人物、選択印、報酬の演出を上に重ねる |
| マップ | `map-carved-tablet.svg` | 欠けた石板、縁の彫り跡、微かな架空の刻印。偽のノードや道を原画に描かない |

4枚の合計は約50KB。SVGは静止画像として読み込み、質感フィルターをライブDOMへ大量に展開しない。原画中の粒や刻印は固定された装飾であり、ゲームの乱数を使わない。

## 利用

`src/components/world/WorldScene.tsx` の `WorldScene` をrelativeな画面コンテナの最初の子として置く。

```tsx
<WorldScene variant="battle" act={act} />
```

`variant` は `battle`・`title`・`ritual`・`map`。自身はabsolute・z-index 0・pointer-events none・aria-hiddenで、同じコンテナ内のキャラクターや情報はz-index 1以上とする。入力、対象選択、スクロール、ゲーム状態には関与しない。

`WORLD_ART` の `src` と `focalPoint` が原画の差し替え窓口。将来専用のイラストを用意したら、画像の参照と焦点を入れ替えればよく、各画面やエンジンを作り直す必要はない。Viteのasset importを使うためGitHub Pagesの `/spyier/` ベースパスにも従う。

`TempleSeal` は、立つ岩と3本の証言線からなる独自の印。装飾専用SVGで、ライブのマップアイコンやカード効果の代用にしない。

## 動きと軽量化

原画は動かさず、少数の光粒と2枚の霧だけをtransform・opacityでゆっくり動かす。OSの `prefers-reduced-motion` と、既存アプリの `reduced-motion`・`speed-instant`・`effects-low` に対応する。軽量設定では光粒を非表示にする。演出のための保存値・ゲームタイマー・乱数は追加していない。

## 検証

4枚ともXML構文検証に成功し、Chromiumで1600×1000の表示を生成して4枚を目視した。画面組み込み後のキャラクター・文字の視認性、viewport、各設定の検証は画面担当・統合担当の記録を参照する。並行実装中の全体ビルドではカードエンジンの型追加が先行していたため未完成エラーが残っており、背景だけで全体ビルド成功を報告しない。
