# Phase 1 — 戦闘とカードのアートディレクション

開始点 `df05bdc`。戦闘計算・乱数・保存形式には変更を加えず、既存のキャラクターと職業HUDを主役にした構図へ変更した。

## 構図と情報

- 長方形の戦闘パネル、四隅の飾り、中央の試練メダルを表示から外した。背景は元のCSS柱の代わりに、オリジナルの神殿SVGを使う `WorldScene` の4層描画へ接続する。
- 見せ場をキャラクターと遠景の奥行きに置く。PCではプレイヤーと敵の配置を非対称にし、広い画面では両者を大きく表示する。
- 敵予告、HP、ブロック、状態、職業リソースは既存位置と操作を維持し、囲いを取り除いてキャラクターの近くへまとめた。敵の詳細表示も維持する。
- エナジーは岩の結晶、ターン終了は角を欠いた石の札として別のシルエットを使う。山札・捨て札・廃棄札・じっとゲージは常時確認できる。

## カード

- 暗い彫刻面の見出し、石灰色の本文、切り落とした石の角、職業別の鉱物色を用いる。コストは円ではなく六角に近い岩の印に変更した。
- `CardEtching.tsx` に、岩拳・石刃・防壁・星・魂・オーブ・毒・供物・経典の9種類のオリジナルSVG図像を実装した。効果グループと職業から表示を選び、数値の計算には使わない。後から専用イラストへ差し替えられる。
- 1100px以上で手札が2～8枚なら、最大4度の自然な扇状配置。9枚以上とタッチ幅では重なりをなくし、手札内の横スクロールを使う。
- PCのホバー・フォーカスでカードが持ち上がる。ドラッグ、キーボード、詳細固定、タッチでの確認後使用、画面内に収める拡大表示を維持した。詳細ボタンは扇状でも隣カードに隠されない側へ置く。
- 手札本文は14px、広いPCと詳細では15px。長い名前は見出しが伸び、強化プレビュー・原文・現在値は既存の実定義から表示する。長文の全文は拡大詳細内で確認できる。
- 軽減／即時設定ではトランジションを停止し、静的な扇形の位置だけを維持する。

## 検証

- 関連6ファイル427件成功：`hand-layout`、`presentation-targeting`、`upgrade-preview`、`limited-card-ui`、`class-ui-compatibility`、`card-runtime`。
- 本作業中はカードエンジンも別担当が拡張しているため、Phase 1の独立ビルドは `git archive df05bdc` の一時作業ツリーへ、戦闘・カードの変更と共通背景のみをコピーして実施。TypeScriptとViteの本番ビルドが成功した。依存ライブラリの追加なし。500kB超チャンク警告は既存から残る。
- Chromiumで1920×1080、1366×768、390×844の拳僧単体・機巧師3体戦闘を表示し、主要UIとページの高さが画面内にあることを確認。広い画面のキャラクター、ノートPCの扇状手札、スマートフォンのタッチ用手札を画像でも確認した。
- QA担当による全5職業・各画面サイズ、ドラッグと大量手札の結果、最終統合ビルドはアート更新の検証記録へ追記する。

この段階でセーブデータ・カードの効果・敵の行動を変更していない。実機端末の描画速度と全組み合わせの人によるプレイ確認は別途必要。
