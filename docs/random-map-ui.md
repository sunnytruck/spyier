# 分岐マップの表示と操作

`src/screens/MapScreen.tsx` は保存済みの `FloorMap.nodes` と `connections` をそのまま表示します。画面を開いたときや表示倍率を変更したときに、マップの再生成やルートの変更は行いません。旧セーブに保存されたマップも同じ表示を使用します。

## マップの読み方

- 地点のアイコンと日本語ラベルは、通常戦闘・エリート・出来事・商人・休憩所・宝箱・階層ボスを示します。未到達の地点も種類を確認できます。
- 現在地は二重の輪と「現在地」、次に進める地点は明るい輪と「選択可能」、踏破済みはチェック、選べない地点は小さな鍵で区別します。
- 金色の実線は歩いたルート、明るい破線は現在地から進める接続です。通らなかった道は薄く表示します。
- 分岐する地点には小さな分岐数を表示します。接続は保存されたグラフから描画するため、新しいマップの分岐・合流・途切れる直進路も正しく表します。
- 地点や次の目的地にマウスを重ねると、その先につながる経路が明るくなります。次の目的地はキーボードのフォーカスでも同じ表示になります。

## 操作

「縮小」「標準」「拡大」はフロア間の間隔を変更します。文字とボタンは小さくせず、タップしやすい大きさを保ちます。上下スクロールで全12フロアを確認できます。「現在地へ」は次に進めるフロア付近へ表示を戻します。

地点の選択には既存の `getAvailableNodes` を使用します。選択可能なノードだけボタンを有効にし、クリックハンドラーでも接続先かを再確認してから `chooseNode` を渡します。ゲーム側の既存の状態遷移チェックも維持します。

PCでは次の目的地と凡例を左に、マップを右に表示します。スマートフォンでは目的地を上にまとめ、マップの下に「地点の種類とマップの読み方」を開閉できる凡例を置きます。マップ全体をページ幅に収め、地点のタップ領域は44px以上です。

スクロール位置、表示倍率、経路の強調は画面だけの状態です。HP・デッキ・現在地・訪問履歴・乱数状態・保存された接続は変更しません。

## 検証

`src/tests/map-ui.test.ts` は、保存された全ノードと接続が描画されること、現在地などの状態の区別、各倍率での座標の順序、分岐・合流をたどる経路強調、表示によってゲーム状態が変更されないことを確認します。

ブラウザ検証ではPCとタッチ端末相当の幅で、倍率切り替え、スクロール、凡例、接続されたノードの選択、選べないノードの無効化、再読み込み後の保存内容を確認します。
