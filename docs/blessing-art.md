# 祝福を授ける六人の素材

`src/components/BlessingCharacterArt.tsx` は階層開始の祝福画面に使うオリジナルSVGです。外部ゲームの画像・音声・固有デザインは使用していません。

| `characterId` / `artId` | キャラクター | 外見と背景 |
| --- | --- | --- |
| `jitto_god` | じっと神 | 既存の岩尊けいとの岩の顔・肩の「じ」「と」・胸の「じっと教」を残した巨大な神。黄金の瞳、古代神殿、岩の祭壇、光の輪 |
| `yomi_guide` | 黄泉案内人 | 三角の笠と長衣、魂の灯を封じた杖。黄泉の門と青紫の魂霧 |
| `stone_merchant` | 岩商人 | 丸く大きな岩の身体、笑う顔、積み上げた荷物、金貨の盆。市場の縞天幕と石の看板 |
| `star_miko` | 星巫女 | 長い石の髪、白金の祭服と広い袖、星冠と星の杖。星座と天球儀の輪 |
| `oblivion_priest` | 忘却司祭 | 顔を隠す仮面、ほつれた灰色の祭服、消えかけた石板。浮遊して薄くなる文字と岩のかけら |
| `chaos_traveler` | 混沌旅人 | 曲がった旅帽、左右の色と形が違う外套、長いマフラー。虹色に移り変わる道しるべ |

## 差し替え用API

```tsx
<BlessingCharacterArt characterId={character.artId} reducedMotion={reducedMotion} />
```

表示名や効果を持つゲーム側のキャラクター定義から `artId` を渡します。素材側は選択肢・効果・抽選・保存データを扱いません。人物と周辺の飾りは一つのSVG内にあり、画面全体の背景、説明文、祝福のカード、取得結果は `BlessingScreen` が管理します。

SVGの `viewBox` は全員 `0 0 640 520`、幅100%・高さ自動です。色だけを変えた共通人物ではなく、体格・顔・衣装・道具・姿勢がそれぞれ異なります。`data-character-id` と `data-art-id`、日本語の `aria-label` を提供します。未知のIDはじっと神の素材にフォールバックし、画面を落としません。

専用イラストを追加するときは、このコンポーネントの窓口とIDを維持して内部を差し替えられます。じっと神だけは既存の `RockDeity` の神格化素材を再利用しています。戦闘用素材や戦闘演出の実装には変更を加えていません。

## 演出と軽量化

人物は短いフェードと8pxの出現移動、背景はゆっくりした浮遊・星輪・文字の明滅です。混沌の記号はストローク色をゆっくり変えます。操作を待たせる処理や追加の描画ライブラリはありません。

`reducedMotion`、アプリの `speed-instant` / `reduced-motion`、画面の `motion-reduced`、OSの `prefers-reduced-motion` ですべて静止画になります。`speed-fast` / `blessing-fast` では人物の出現時間を短縮します。静止画でも人物・記号・背景を省かず、意味が分かる状態を保ちます。

## 表示確認

六人すべてについて1366pxと390pxの幅で確認しています。SVGの描画範囲は640×520内に収まり、横はみ出しはありません。同時表示でも `useId()` による定義IDが重複せず、静止設定ではアニメーションが停止します。
