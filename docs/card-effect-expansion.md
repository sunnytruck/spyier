# カード効果エンジンの拡張

今回追加したカードも、既存の `Effect[]` と共通の解決処理を使います。カードIDごとの戦闘分岐は追加していません。TXTの明確な記述から実装できる効果を選び、未対応の記述を近似したカードは報酬へ混ぜません。

## 共通の効果処理

| 処理 | 内容 |
| --- | --- |
| 動的な数値 | 手札・山札・捨て札・廃棄札の枚数、対象の状態異常、生存敵の毒の合計、オーブの数・種類数・生存敵数を参照 |
| 攻撃回数 | 支払ったXエナジー、Xの条件付き倍化、状態異常による追加ヒット、オーブ数によるヒット数 |
| ランダム攻撃 | ヒットごとに生存敵から抽選し、敵撃破後の追撃対象を更新 |
| 条件付き効果 | 対象の毒・弱体・脆弱、攻撃予告、当ターンの使用カード数を確認 |
| 一時効果 | 筋力・反撃・攻撃時ブロックなどを敵の行動終了まで保持し、次のプレイヤーターンの前に自分の追加分を解除 |
| 次ターンの効果 | ドロー、ブロック、星などを予約し、次のエナジー回復・ターン開始効果の後、通常ドローの前に一度だけ解決 |
| 手札操作 | 所定枚数までドロー、手札をすべて捨てて同枚数ドロー、ランダム廃棄 |
| カード移動 | 手札・捨て札から指定枚数を選んで山札の一番上へ戻す、捨て札から手札へ戻す |
| 数値の倍化 | 現在のブロックまたはエナジーを倍化 |
| オーブ | 全オーブの解放、支払ったXを使う解放、種類数に比例する集中力、敵数に比例する生成 |

生の参照値は `engine/combat/values.ts`、攻撃の基礎値とヒット数は `resources.ts` の共通関数を使用します。戦闘画面の現在値プレビューも同じ関数を使います。手札枚数は、使用中カードを手札から取り出した後の数です。使用枚数は、そのカード自身を加算した後の値です。

筋力を失う新カードは、明示的な `allowNegative` を使います。既存カードの状態異常処理は従来の0下限を維持します。負の筋力も通常のダメージ式を使用し、攻撃値は0未満になりません。

## 中断と復元

カード選択は `pendingChoice` に移動元を保存します。選択中は他のカード使用・ターン終了を拒否し、確定後に残りの効果と使用中カードの移動を一度だけ実行します。対象が0枚なら次の効果へ進み、全候補を選ぶ場合は自動で移動します。手札上限50枚を越える回収は行いません。

次ターン予約は `scheduledEffects`、一時効果の解除情報は `turnModifiers` に必要時だけ保存します。旧セーブに新しい既定フィールドを挿入しません。予約キューを取り出して削除してから効果を実行するため、再読み込みで処理済み予約が再実行されることはありません。セーブ読込では実在カードに記載された予約効果のみを受け入れます。

ゲームの乱数は既存のシード付き乱数生成器だけを使用します。候補のない廃棄、0回攻撃、勝利後の追撃は乱数を進めません。演出は既存の戦闘イベントに接続し、数値の追加効果を発生させません。

## 検証と実装範囲

`expanded-card-engine.test.ts` でXの境界値、敵ごとの条件判定、全滅時の追撃停止、一時効果の重なり、予約の保存・一度限りの実行、手札操作、異なる札置き場からの選択、ネストした条件の継続処理を検証します。追加カードは別途、通常版・強化版についてTXT由来の独立した期待値で検証します。既存カードの状態・乱数・保存データが変わらないことは既存の互換性テストで照合します。

今回採用した参照カードに不要な、自動使用・変身・任意カードコピー・一時コスト変更は追加していません。未対応カードは引き続き参照データとして保持し、取得プールから除外します。将来追加する際は、選択の中断・生成カードの所属・連鎖の停止条件も含めて実装します。
