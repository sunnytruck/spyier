# 階層開始時の祝福

## 登場人物と抽選

第1階層では必ず「じっと神」が登場します。以降は、じっと神・黄泉の道案内・石ころ商人・星詠みの巫女・忘却の司祭・混沌の旅人の6人から重み付きで抽選し、直前と同じ人物を除外します。人物と選択肢には専用のシード付き乱数を使い、戦闘・マップ・報酬の乱数状態を変更しません。

各人物には独立したイラストID・背景テーマ・演出テーマ・登場可能階層・複数の台詞を定義します。台詞も専用シードで選び、選んだ番号を遭遇データに保存します。

各登場人物は得意な祝福が出やすくなります。常に有効な4つの異なる選択肢を用意し、安全な報酬と代償のある報酬を両方含めます。代償を支払えないもの、強化対象が足りないもの、重複レリック、他職業専用レリックは出現させません。

## 報酬と代償

18種類の定義を共通の処理で組み合わせます。最大HP増加と同量の現在HP増加、回復、ゴールド、カード削除・強化・変化、職業カード、レアカード、レリック、2枚変化、職業の仕組みに関連する2枚のカードを扱います。階層が上がると定義に従って量や代償が増えます。

HPの代償は支払い後に1以上残る場合だけ選べます。最大HP減少は現在HPも新しい上限まで下げます。呪いの代償は、既に動作する「石心の迷い」を実際にデッキへ加えます。カード削除でデッキを0枚にはできません。

職業カードは既存の職業別取得プール、レリックは職業適性と未取得条件を使います。変化は同じカードを除く職業プールから選び、元のUIDを保って強化状態を解除します。専用カードの選択肢は `getBlessingCardPool` に資料確認済み・実装済みのカードがある場合だけ出現し、空の場合は通常の有効な選択肢で4つを満たします。

専用カードの祝福には最大HPの代償（第1階層5、第2階層7、第3階層9）を設定します。カード本文の効果量やコスト自体は変更しません。

人物の `blessingCardIds` で限定カードの候補を絞れます。未設定なら全8枚、空配列なら限定札の選択肢なしです。許可リストでも通常札・基本札・生成札・他職業札を限定報酬に変更することはできません。生成と保存検証の両方が同じ制限を参照します。現在の6人は全8枚を許可し、限定札が出やすい人物の傾向は `optionTemplateIds` で分けています。

## 保存と確定

遭遇した時点で4候補のカードID・レリックID・代償・効果量を保存します。変化は全ての選択可能カードに対する変化先をこの時点で固定します。

削除・強化・変化では、選んだ祝福と対象カードUIDを先に保存します。2枚選ぶ場合は1枚だけ選んだ途中状態も保存できます。確定前に別の選択肢へ切り替えても候補や変化先は変わりません。確定操作でだけ代償と報酬をまとめて反映し、結果明細と階層ごとの受領履歴を同時に保存します。

結果画面では再確定できず、継続はマップへ進むだけです。履歴に同じ階層を追加する処理も拒否します。再読み込み後の対象選択・結果明細は保存値から復元します。旧セーブの祝福・階層フィールドがない場合は、そのまま従来の進行を続けます。

保存検証では、候補の代償・効果を定義と照合し、カード・レリックの取得条件、対象、結果明細、確定後の状態、階層履歴の連続性を確認します。保存候補を再抽選せず、不正な数値や重複受領を受け入れません。
