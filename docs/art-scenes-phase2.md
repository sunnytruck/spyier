# Phase 2：神殿の入口・祝福の儀式・彫り石の地図

2026-10-21。Phase 1 `3e9c357` を引き継ぐ。ゲーム計算・カードやレリックの定義・乱数・報酬・セーブ形式は変更しない。

## 実装した構図

- タイトル：大きな岩尊けいと、遠景の塔と崩れた神殿門、独自の岩信仰の紋章とロゴ。機能説明の均等なパネルを廃止し、開始・保存した探索の再開を縦のメニューで選ぶ。練習とその再開、教え、シード指定、上部の設定・図鑑は維持。シードは開閉できる小さな「運命の刻印」に収める。
- 祝福：中央の神・祭壇と手前の小さな岩尊に対し、左右に高さと位置をずらした四つの供物を置く。長方形4列を廃止し、生命・金・カード・限定カード・レリック・削除・強化・変化の独自SVG紋章と色、代償の傷跡で区別する。効果と代償は常時全文、台詞的な説明は開閉。選択は確認モーダルで詳細・対象・実定義のカードプレビューを見てから確定する。
- 祝福の獲得：選ばなかった供物が消え、受領した紋章が手前の岩尊に向かって吸収される。獲得結果は既存の確定済みreceiptだけを表示し、演出から報酬を再計算しない。速度設定・演出スキップ・アニメーション軽減・OSの軽減設定に対応。
- マップ：説明を余白の小さな注記にし、彫り石の地図と接続線を画面の主役にする。章説明と凡例は開閉。既存SVGノード、現在地・通過済み・次の候補・選択不能の区別、倍率・現在地への移動・接続判定を維持。ページの高さを固定し、地図の内部だけをスクロールする。

背景は `WorldScene` と `src/assets/world` のオリジナルSVGを使う。後から絵を差し替える際は共通manifestを変更する。画面専用CSSは `art-scenes.css` にまとめ、Appの共通CSS読込の最後に一度だけ読み込む。

## 操作と互換性

Appのタイトル分岐を表示コンポーネントへ抽出した。開始・再開・練習・保存・dispatchは既存のコールバックを使用する。祝福の4択、候補・選択対象の保存、未確定プレビュー、二重取得防止、Act遷移は既存の状態機械を維持する。確認を閉じても選択は保存され、再読込時は確認へ戻る。

スマートフォンでは読みやすさを優先し、祝福を神の登場から四つの供物へ続く縦の儀式にする。職業選択画面を下までスクロールした直後でも、新しい祝福の入口を先頭から表示する。旧モバイルCSSの相対配置による神名・台詞の切れを解消した。
