# 拡張カードの戦闘中表示

カードの本文・強化本文はカード定義をそのまま表示します。追加の「現在の戦闘での効果」は `src/presentation/cardRuntime.ts` で読み取り専用に計算します。

## 計算方法

表示用に戦闘状態を複製し、実際のカード使用と同じ順番でコスト、敵の反応、カード使用時レリック、最初の攻撃のレリック、攻撃時ブロックを解決します。その後、各効果を順に既存のリゾルバーへ渡します。元の戦闘状態、手札、乱数、レリック回数、予約効果、セーブ内容は変えません。

| 表示対象 | 参照する戦闘エンジン |
| --- | --- |
| 手札・山札・捨て札・廃棄札・毒・破滅などによる威力 | `combatValue`、`attackCardBase` |
| Xコスト、オーブ数、条件による攻撃回数 | `attackHitCount` |
| 筋力・弱体・敵ごとの脆弱 | `calculateDamage` |
| ブロック・破滅・オーブ生成・集中力の参照量 | `scaledEffectAmount` |
| 条件分岐 | `meetsEffectCondition` |
| オーブの解放順・発動値 | `nextOrbEvokeIndex`、`orbEffectValue` |

攻撃値は各ヒットのブロック軽減前です。全体攻撃は各敵の補正を別々に計算します。X＝0や保持オーブ0による攻撃0回も表示します。X解放が0回でも右端のオーブが取り除かれる既存の処理を明示します。

条件付き効果は先行効果の解決後に判定し、条件不成立なら追加の数値を表示しません。途中でプレイヤーや敵が倒れた場合、続く効果は表示・解決を止めます。

## 未確定の結果

- ランダム攻撃は現在の生存敵に対する威力の範囲と回数を表示し、抽選される敵を公開・保証しません。
- 抽選に続く効果がある場合は、抽選後の数値を確定済みとして表示しません。
- カード選択が必要な場合はそこで予測を止め、後続効果が選択後に解決されることを表示します。
- 次ターン効果は予約する定義と数値を表示します。現在の効果へ加算したり、未来のHP・状態・対象を推測したりしません。発動条件とタイミングも説明します。
- 一時的な筋力・パワーは現在値から適用後の値を表示し、永続分を残して次の自分のターン開始前に解除することを説明します。

`src/tests/card-runtime.test.ts` の57件で既存22件を維持し、追加の参照量、X、全体・ランダム攻撃、条件分岐、次ターン予約、一時効果、カード選択、全カード通常・強化版の読み取り専用性とセーブ・ロード後の一致を確認しています。
