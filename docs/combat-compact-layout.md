# 戦闘画面のコンパクト化

## 実装

- `BattleScreen` に戦闘専用の `compact-battle` クラスを追加。既存の画面デザイン、キャラクター、演出・対象アンカー、カード使用コールバックは継続使用する。
- 戦闘時だけ上部ヘッダーを縮め、残りの `100dvh` を「戦闘情報／戦場／操作バー／手札／ログ」の5行に配分。手札はページの通常スクロールから独立し、常に画面下部に残る。
- 敵・プレイヤーをスマートフォンでも左右に配置する。行動予告、HP、ブロック、状態、5職業のリソースを常時表示する。オーブは拡張スロットにも対応する。
- 上部の常設敵説明を削減。敵画像のホバー説明と、敵名横の「ⓘ」から開く詳細ダイアログに移す。詳細を開いても攻撃対象やゲーム状態を変更しない。
- 山札・捨て札・廃棄札の確認ボタンと枚数、エナジー、ターン終了をコンパクトな操作バーに配置。星のHUDも同じ行に維持する。
- レリック拡張で追加された敏捷・活力・プレートを状態チップに表示し、説明文を付ける。
- 手札の横スクロール・拡大プレビューは `BattleHand` 担当の変更と共通レイアウト契約（PC 250px、スマートフォン 215px）で統合する。
- 戦闘ロジック、セーブ形式、ダメージ計算、ゲームバランスにはこのUI変更から手を加えていない。

## 再開後の修正

- スマートフォンの連続タップで、タッチ後のフォーカスが先にホバープレビューを開き、互換クリックを奪う不具合を修正。タッチではクリックで確認画面を開き、Tab入力ではキーボード用フォーカスプレビューへ戻る。法王・機巧師で3枚を続けて確認・使用できることを実ブラウザで確認した。
- 状態チップの説明を画面内に位置調整するbodyポータルへ移動。端の敵でも手札やキャラクターの重なりに隠れず、ホバー・フォーカス・タップで読める。
- 防御・支援・状態異常の行動予告は、同じ保存済みintentの数値を短く表示する。全文は敵の詳細とホバー説明に残す。
- 375×667の低い縦持ちスマートフォンでは、手札185px・カード148px、装飾と余白を縮小。3体の敵を同時表示し、HP・状態・行動予告と操作バーが重ならない配置にする。オーブ6枠や岩霊も維持する。

## 検証状況

- TypeScript の `tsc -b` 成功。手札拡大位置の境界テスト6件成功。
- Chromium で 1366×768 と390×844の実画面を確認し、機巧師の既存固定高さ・モバイル操作バーの縦並び・廃棄ボタン非表示の継承ルールを修正。
- 375×667で全5職業・3体の長い行動予告・15枚手札・状態異常・6枠オーブを検査し、敵情報が戦場内に収まりページ全体の縦横スクロールが発生しないことを確認。
- 全5職業 × 単体・複数敵・大量手札 × 1920×1080／1366×768／390×844 の45組、ドラッグ等15組、50枚手札等5組が固定した本番ビルドで成功。詳細と未検証範囲は [ブラウザ検証](combat-compact-validation.md) に記録。

## 留意点

- 非常に低いウィンドウでは必要情報の可読性を優先して戦場の最小高さを確保する。一般的なPCサイズと縦持ちスマートフォンが主検証対象。
- 小画面でポーション枠や発動中パワーが特に多い場合は、それぞれの小領域内だけを横スクロールする。
