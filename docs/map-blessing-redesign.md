# マップと祝福確認の再設計（2026-10-21）

基点 `1f0b681`。開始時の作業ツリーはクリーン。今回の対象はマップと祝福確認だけで、戦闘・カード・他の画面・ゲームエンジン・保存形式は変更しない。

## 1. 地図を主役にする

`MapScreen.tsx` からサイドバーをDOMごと削除。章説明・次の3経路ボタン・常設の説明行・モバイル用説明欄を取り除き、コンパクトなヘッダーと全幅の地図にする。旧930px／890pxの幅制限も解除し、画面の残り高さを地図の内部スクロールへ割り当てる。

- ヘッダー：Act／階層名、縮小・標準・拡大、現在地へ。
- 進行：ノードを直接押す。移動可能ノードだけが既存 `chooseNode` アクションを発行し、接続判定はエンジンへ委ねる。
- 詳細：ホバー・キーボードフォーカス・タップで一時表示。未接続／踏破済みノードも閲覧可能だが、進行アクションは発行しない。
- 現在地／進行可能／踏破済み／未到達／移動不可能は既存保存状態から表示し、色・輪郭・チェック・ラベルを併用。
- 拡大縮小は地図の幅・高さ・ノード寸法へ反映。現在地ボタンは横方向も含めて保存済みの位置へ戻す。フロア文字をSVGの横伸びから分離する。
- 新スタイル `map-sanctuary.css` は新しい地図classへ限定し、他画面のCSSを変更しない。文字・操作を最小44pxのヒット領域で扱う。

`npm run build` とマップ関連3ファイル25テスト成功。入口／合法に進んだ2Fの2状態×1920・1366・390幅の6ケースも成功。sidebar DOMなし、ページの縦横はviewport内、地図幅1848／1311／374px、直接選択後の保存全文と再読込の一致、ブラウザ例外0を確認した。
