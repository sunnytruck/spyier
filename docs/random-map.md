# シード付き分岐マップの拡張

## 今回の変更

以前は各フロアの部屋種別が固定され、3本の直進ルートへ任意の接続を加えていました。新しいゲームでは接続と部屋配置をそれぞれシード付き乱数で生成します。12フロア、34ノード、3列と既存のノードID形式は維持します。

- 隣接する列だけを結ぶ、交差しない9種類の接続パターンを使います。
- 各部屋に必ず次の接続があり、次フロアの全部屋にも進入できます。
- 分岐と合流が生じ、少なくとも1区間では中央の直進接続がありません。常に3本の直線が続く構造には戻りません。
- 全ノードが入口から到達でき、どの選択肢からも最終ボスへ進めます。
- 同じシードは同じ接続・同じ部屋配置を生成します。乱数にはマップ専用の名前空間を使い、戦闘・報酬・イベントの乱数状態を消費しません。

## 部屋の配置と難易度

最初の2フロアは通常戦闘、第11フロアは休憩所、第12フロアはボスです。第3〜10フロアは重み付きの制約充足で配置します。序盤はイベント、中盤は商人・休憩、終盤は通常戦闘の重みを高めています。

| 種別 | マップ全体の数 | 配置条件 |
| --- | ---: | --- |
| 通常戦闘 | 13〜18 | 最初の2フロアを含む |
| エリート | 3〜4 | 第5/6フロアのどちらかと、第8/9フロアのどちらか |
| イベント | 5〜6 | 第3〜10フロア |
| 商人 | 2〜3 | 各ルートで最大2回 |
| 休憩所 | 4〜5 | ボス直前の3部屋を含み、各ルートで最大3回 |
| 宝箱 | 1〜2 | 第3〜10フロア |
| ボス | 1 | 第12フロア |

通常戦闘同士を除き、接続された部屋が同じ種別で連続することはありません。エリートを避けられるルートと、2回挑めるルートをどちらも保証します。全ルートにボス前の戦闘を最低4回（通常・エリートの合計）確保し、準備不足のままボスへ到達する経路を防ぎます。

部屋の個数もシードで変わります。制約探索には上限を設け、配置できなければ同一シードから派生した次の候補を使います。外部状態や時刻を参照しません。

## セーブ互換性

保存済みマップはそのまま読み込みます。新しい配置条件は新規ゲームの生成だけに適用し、既存の `validateMap` の構造検証は変更していません。旧版で生成された直進ルートや連続した特殊部屋も引き続き有効です。ロード時に部屋・接続・現在地・乱数状態を再生成する処理は追加していません。

## 検証

`src/tests/map-expansion.test.ts` で同一シード再現、接続と部屋分布の多様性、交差防止、到達可能性、部屋数と連続制限、全ルートの難易度条件、戦闘乱数からの独立、旧セーブの復元と破損拒否を確認します。既存 `map.test.ts` の100シード検証も維持します。
