# 職業別キャラクター・固有リソースUI

職業IDや戦闘状態の保存形式を変えず、既存の戦闘リソースを常時表示します。HP・ブロック・エナジーは共通の位置に残し、職業リソースはプレイヤーの周囲に配置しています。

## 表示と計算の境界

- `src/engine/combat/resourceView.ts` は状態を変更しない表示用セレクターです。表示のために乱数やカード処理を実行しません。
- `src/components/classResources/` は表示と詳細ダイアログを担当します。カード使用やリソースの更新を直接行いません。
- 戦闘画面には演出タイムラインの状態が渡されるため、リソースの増減表示はカード・攻撃の演出に同期します。
- 保存する項目や既存の職業ルールは変更していません。再読み込みでは保存されたエンジン状態から表示を復元します。

## 職業ごとの表示

| 職業 | 常時表示 | タップ・クリックによる詳細 |
| --- | --- | --- |
| 岩砕の拳僧 | 筋力、手札のHP消費カード数 | カードごとのHP消費、現在HPでは敗北する場合の警告、連続攻撃・ブロック攻撃のルール |
| 静刃の影師 | 石刃強化、手札の石刃枚数、敵の毒と次の毒ダメージ | 石刃の現在の威力、敵ごとの毒処理後の値 |
| 星詠みの法王 | エナジー横の所持星・当ターン獲得星、鍛造・聖剣の基礎威力 | 星参照カードの現在値、聖剣の実際のコスト・カード定義・鍛造後の威力 |
| 黄泉渡りの霊僧 | 独立した岩霊キャラクター・HP・召喚状態、敵の破滅 | 岩霊の護衛条件と手札の命令、毒の後に判定する破滅の発動条件 |
| 岩核の機巧師 | プレイヤー周囲の空きを含むオーブスロット、保持数、集中力、一時集中力 | スロットごとの集中力補正後の自動・解放値と右端からの解放ルール |

星は既存の実装に従って蓄積・参照する値です。星消費コストは追加していません。岩霊は命令カード使用時だけ攻撃し、自動攻撃は行いません。

オーブは配列順をそのまま表示し、右端の保持オーブを「次に解放」と表示します。スロットの上限・効果量は共通エンジン定義を参照します。雷はランダムな生存敵を対象とし、筋力・弱体・脆弱を参照しません。

## 演出用DOMの接続点

- `data-battle-actor="player"`：職業別の岩尊けいと。
- `data-battle-actor="orb-0"` 〜 `orb-2`：配列添字に対応したオーブスロット。空きスロットも保持します。
- `data-battle-actor="osty"`：独立した岩霊。HP0へ遷移した際は、肩代わり・消滅のキューが終わるまで召喚時の絵を残します。
- `data-resource-hud="stars"`, `forge`, `focus`, `strength`, `knife`, `ostyHp`：リソース変化時の演出対象。
- 演出側は内側の `.resource-motion` を操作でき、レイアウト用のボックスを移動させません。

## 操作・レスポンシブ

すべてのリソース詳細は通常のボタンで開くダイアログです。マウスのホバー説明に加えて、タッチとキーボードで確認できます。ダイアログのフォーカス移動・Escape・閉じた後のフォーカス復帰は既存の共通 `Modal` を使用します。React Portalで `.app` 直下に表示するため、キャラクターの演出レイヤーや敵のターゲットボタンに遮られません。

PCではキャラクターの周囲にリソースをまとめ、狭い画面ではプレイヤーと敵を2段に配置します。法王の星とエナジーは同じ行に並べ、ターン終了ボタンを次の行に配置します。本文は既存の日本語ゴシック体を継承します。

毒・破滅の予測は現在のHP・状態値に対する次の敵ターン開始処理です。カード使用などで状態が変われば、その時点の値で再計算します。攻撃の表示値は敵のブロックで軽減される前の値です。
