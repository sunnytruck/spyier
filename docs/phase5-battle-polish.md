# Phase 5 — 戦闘表示の仕上げ

Phase 1 の構図・手札操作を維持したまま、追加カードの状態表示とドラッグ中の見た目を仕上げた。戦闘計算、乱数、保存形式の変更はこのUI作業には含めない。

## 変更

- ドラッグ中のカードは `document.body` に表示されるため、画面内のカードだけに適用されていた新しい石枠・職業色・SVG図像・本文色が外れていた。詳細表示とドラッグの両ポータルにも同じアートを適用し、手札とドラッグ表示の見出し・本文・コスト・図像の寸法を同じCSS定義から切り替える。
- 新カードが付与する「ドロー不可」「ブロック保持」「次ターン保持」を、プレイヤーの状態欄に短い日本語ラベルで常時表示する。`CombatState.drawBlocked` と `powerStacks.retainBlock` / `retainBlockNextTurn` を直接参照し、UI側で有効期間を再計算しない。
- 永続保持中は次ターン保持の重複表示を抑える。ターン開始で解除される状態は実際の戦闘状態が変わると表示から消える。ドロー禁止と直接手札へ加える効果、ブロック保持と攻撃によるブロック消費の違いを説明する。
- 状態の説明は既存のホバー・フォーカス・タップ式ツールチップで表示する。画面端でも説明を画面内へ収め、短ラベルは12pxの日本語ゴシック体で表示する。既存のセレクター・ラベル・タッチ操作を維持した。

## 検証

- `hand-layout` / `presentation-targeting` / `upgrade-preview` / `card-runtime`: **4ファイル396件成功**。
- `npm run build`: **成功**。既存の500kB超チャンク警告は残る。
- Chromiumで1920×1080、1366×768、390×844の各画面幅を使用。保存済み状態から一時保持・永続保持の2ケースずつ、計6ケースを確認した。ページの縦横スクロールなし、状態の短ラベルと説明表示、説明確認・ドラッグ取消によるセーブ不変、ターン終了後の一時状態解除と永続保持の継続を確認した。
- 同じ6ケースで、手札とドラッグ中の職業色・本文サイズ・図像高さ・コストサイズが一致することをブラウザの計算済みスタイルで検証した。本文は広いPCで15px、ノートPC・スマートフォンで14pxを維持する。
- 1366×768で5職業それぞれのカードをドラッグし、職業色・石の背景・本文色・図像高さが手札と一致すること、取り消した場合にセーブが変わらないことを追加確認した。
- 検証用の戦闘状態は表示ストレス用に配置したものであり、バランスや勝率の評価ではない。全5職業の表示・操作、50枚手札、職業HUD、戦闘演出、エンジンの全回帰結果は今回の統合検証記録を参照する。

証跡は作業環境の `/tmp/spyier-art-phase5/` に保存した。再開時の恒久的な根拠はこのメモ、関連テスト、統合したブラウザ検証スクリプトとする。
