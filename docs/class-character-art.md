# 職業別キャラクター素材

5職業とも岩尊けいとの岩の顔・肩の「じ」「と」・胸の「じっと教」を共有し、衣装だけでなく姿勢・輪郭・装備で見分けられるオリジナルSVGです。外部のゲーム素材やフォント配信には依存しません。

| 職業 | 外見 |
| --- | --- |
| 岩砕の拳僧 | 赤い鉢巻と道着、大きな岩の拳、低く踏ん張る脚 |
| 静刃の影師 | 深緑のフード、紫の外套、両手の石刃、低く傾いた構え |
| 星詠みの法王 | 星冠と星の後光、白金の長衣、大きな聖剣 |
| 黄泉渡りの霊僧 | 青紫の頭巾と長衣、魂の灯を封じた杖 |
| 岩核の機巧師 | 分割装甲、光る回路、機械関節、背中の雷撃コイル |

## 差し替え用インターフェース

`src/components/CharacterArt.tsx` の `RockDeity({ classId?, deified? })` が公開窓口です。`classId` を渡すと `ClassCharacterArt.tsx` の職業別素材を表示し、省略すると従来の筋肉質な岩尊けいとの素材を表示します。タイトルや旧セーブの見た目も維持します。神格化時の輪と光も引き継ぎます。

`OstyArt({ active?, className? })` は岩霊専用の独立SVGです。未召喚時は魂の灯が消えた輪郭、召喚時は岩の身体と明るい魂の灯を表示します。HP・肩代わり・攻撃能力を素材側に持たせず、共通HUDと演出イベントに任せています。

職業別素材の部品に実際のオーブや星の所持数は描きません。可変リソースは戦闘エンジンの状態を参照する専用HUDが表示するため、装飾と実際の所持数が混同されません。SVG定義のIDは `useId()` で分離し、同時表示してもグラデーション参照が衝突しません。

専用イラストに変更する際はこの公開窓口を維持し、`character-art rock-deity` クラスと職業を識別する `data-character-class` を残してください。戦闘側の移動・被弾・速度設定は外側のコンテナが管理します。素材自身は自動で動かさないため、演出スキップ・軽量設定と競合しません。

職業選択画面では選択と同時に姿が切り替わり、クリア・敗北画面にも選択した職業の姿を引き継ぎます。
