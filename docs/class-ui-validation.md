# 職業別 UI の検証と互換性

この変更の対象は、既存の 5 職業の情報表示・外見・戦闘演出です。カード ID、カード効果、敵の行動、レリック、乱数、セーブのバージョンは維持します。

## 変更前の戦闘を固定した回帰テスト

`src/tests/fixtures/class-resources-before-ui.json` は、変更前のコミット `60fd02d060c0570850911fd0fc23e6f532a582ba` を `git archive` で `/tmp` に展開し、その古いエンジンを使って取得したデータです。現在のエンジンから期待値を作り直していません。

16 シナリオ、合計 68 回の公開アクションについて、完全な `serializeGame` 出力の SHA-256 と乱数の内部状態を保存しています。最初のセーブは文字列のまま保持し、元のバージョン 1 戦闘セーブを復元します。テストは各アクションを通常実行と演出トレース付き実行の両方で検証し、入力を変更していないことと、毎回の保存・復元が一致することも確認します。

対象は以下です。

- 機巧師：満杯のオーブ、右端の解放、同じオーブの連続解放、並び順、集中力の正負、ターン終了時の自動発動、一時集中力の失効。
- 霊僧：召喚・HP の増加・召喚攻撃、プレイヤーの筋力／弱体からの独立、ブロック後の肩代わり、全体攻撃の独立した被弾、消滅、破滅による勝利、魂札の生成。
- 法王：星の獲得、このターンの獲得数を参照する攻撃、星を消費しないこと、ターン開始時の獲得数リセット、鍛造、聖剣の生成・攻撃。
- 拳僧：筋力、ブロックを消費しない HP 支払い、ブロック参照の攻撃、多段攻撃。
- 影師：石刃の生成・追加ダメージ・廃棄、毒の付与・ブロックを無視するダメージ・蓄積数の減少。

通常カードと強化カードの両方を含みます。星の所持数が多くても、このターンの獲得数が 0 なら星参照攻撃が不発になるケースも固定しています。

実行:

```bash
npm test -- src/tests/class-ui-compatibility.test.ts src/tests/class-runs.test.ts
```

期待値を再取得する必要がある場合は、まず変更前のコミットを別ディレクトリに展開してください。`src/tests/helpers/captureClassResourceBaseline.ts` をその展開先の同じ相対パスにコピーし、展開先の古いエンジンに解決されることを確認してから esbuild で実行します。更新後のエンジンを使って期待値を上書きすると、互換性の検証になりません。

## 正しい情報源と表示上の注意

- オーブは最大 3 スロットです。満杯時とカードによる解放はどちらも右端を対象とします。連続解放は同じ右端の 1 個を繰り返し発動し、取り除くのは 1 回です。
- オーブの発動値は集中力補正後に 0 未満になりません。雷の対象は既存のシード付き乱数が選びます。自動発動は一時集中力の失効前に起こります。
- 岩霊は自動攻撃しません。対応カードで攻撃し、HP が 0 のときは攻撃できません。通常攻撃はプレイヤーのブロックを先に使ってから肩代わりします。全体攻撃はプレイヤーと岩霊に独立して当たります。HP 支払いと毒は肩代わりしません。
- 星の所持数と当ターンの獲得数は別の値です。星を参照する現在のカードは、獲得数を参照するだけで星を消費しません。通常のエナジーコストは変わりません。
- 破滅は敵のターン開始時、毒の解決後に現在 HP 以上なら発動します。毒は次の敵ターン開始時のダメージを予測し、以降の未確定ターンの総ダメージとしては表示しません。
- 演出イベントは保存対象ではありません。再読み込み時に過去の召喚・攻撃・解放をもう一度処理せず、保存済みのリソース状態を表示します。

## ブラウザでの確認項目

各職業で、開始時・リソースを持つ状態・強化カードを持つ状態を確認します。機巧師は空スロット／満杯／負の集中力、霊僧は未召喚／召喚／肩代わりによる消滅、法王は星 0／獲得／参照／鍛造を含めます。

- PC とスマートフォン幅で、固有 HUD が敵の行動予告・キャラクター・手札を隠さず、文章が切れないこと。
- 説明をキーボード・マウス・タップで確認でき、説明を開いてもカードを誤使用しないこと。
- ドラッグ、カードの連打防止、速度変更、演出スキップ、軽量表示を維持していること。
- カード使用直後の保存は実際の戦闘結果と一致し、演出中にリロードしても使用前に戻らないこと。
- 保存して再読み込みした後も、オーブ順・集中力・岩霊 HP・星・当ターン獲得数・鍛造・石刃強化・毒・破滅が一致すること。
- 第 1 階層の正規の公開アクションで、5 職業ともボス撃破まで進めること。防御せずターンを進めた場合の敗北も維持すること。

- 変更前のエンジンで生成した 17 種類のセーブを、1366×768 と 390×844 で復元する計 34 ケースを確認しました。各ケースでカードを 3 枚使用してターンを終了する計 136 回の操作について、変更前の完全なランの保存文字列と一致しました。各操作後の HUD と最後の再読み込み後の値も一致しました。
- 5 職業の通常状態と 4 職業の敵 3 体状態を、1920×1080・1366×768・390×844 で確認する 27 ケースを実施しました。横方向の画面のはみ出し、手札の説明・現在値の切れ、敵の予告と状態・毒／破滅表示の重なりがないことを確認しました。
- 職業 HUD・オーブ・岩霊・星の詳細ダイアログを計 57 回開き、開いた状態で `E` と `1` を押しても保存が変わらず、閉じるボタンを通常のクリックで操作できることを確認しました。敵 3 体の毒・破滅の詳細も PC／スマートフォンで計 12 回タップし、処理順と予測値、同じキー操作による非変更を確認しました。

### 最終の自動検証

`npm test`：32ファイル、1,313テスト成功。`npm run build`：TypeScriptとViteの本番ビルドが成功。新規依存パッケージとセーブ形式の変更はありません。メインJSが500kBを超える既存のVite警告は残っており、今後の分割・初回読み込み改善の対象です。
