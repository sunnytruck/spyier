# ランダムマップ・カード・バランス拡張の進捗

基点：`855b85c`。既存の5職業、HUD、キャラクター、戦闘演出、カードID、保存キーと保存バージョンを維持する。資料の未確定効果・星コスト・他プレイヤー参照を推測で実装しない。

## 開始時の調査

- 参照資料574件、実行可能な参照カード86件、未実装488件。職業ごと16件、無色6件。基本札・生成札も参照への対応数に含む。
- マップは12階・34ノード。従来は階ごとの固定種別をシャッフルし、同じレーンを常に接続していた。保存にはノード全体・接続・訪問履歴が既に含まれる。
- 戦闘報酬は職業限定、ショップは自職業と無色。未実装・生成専用・基本札は報酬から除外。従来の抽選はレアリティを考慮しない均等抽選。
- マップとランの初期乱数は別シード。戦闘ごとにシードを渡す。保存復元時はマップと報酬を再生成しない。
- 既存の通常敵・エリート・ボス、イベント、レリックを引き続き使用し、12階ボス撃破で第1階層を完了する。

## 最終結果

41ファイル・2,424テスト成功、本番ビルド成功。5職業すべて本番ビルドのブラウザでタイトルから12階ボス撃破まで到達。150回の自動探索は125勝25敗、全周ボス到達・無効状態と停止なし。マップの1,000以上のシード、PC／スマートフォンの経路・長文カード・強化・回収選択・保存復元・演出設定を検証した。

旧68戦闘結果の保存文字列と乱数は一致。旧マップ・報酬・ショップを再抽選せず、保存キー・バージョンは維持。霊僧の構築とボス戦、実機確認、JS容量の最適化は継続課題。詳細は `roguelike-validation.md`、`roguelike-ui-validation.md`。

## 再開する場合

`git status --short` と本書、各追加設計書を確認する。既存の変更を破棄・リセットしない。担当ごとのデータファイルを統合した後、`npm test` と `npm run build` を実行する。取得プールへ入れるのは両バージョンの効果が実装・検証されたカードだけ。旧マップは保存された構造をそのまま使い、新しい配置ルールを旧セーブへ強制しない。
