# 階層開始時の祝福画面

`src/screens/BlessingScreen.tsx` は、階層の入口で表示する専用の画面です。既存のイベント画面とは分け、中央のキャラクター、祭壇、四つの祝福、対象選択、受領結果を一つの流れにまとめています。

## 表示する情報

- `BLESSING_CHARACTERS` の名前・肩書き・説明・`artId`・背景テーマ・演出テーマを参照します。会話は保存された `dialogueIndex` を使い、再読み込みで抽選し直しません。
- 第1階層では大きな「じっと神」を中央の祭壇に配置します。ほかの出会いも同じ画面で、それぞれのSVG、色、背景に切り替わります。
- 四つの選択肢は、エンジンが保存した報酬ID・数値・代償をそのまま表示します。HP・最大HP・ゴールド・既存の呪いを区別します。
- カードの詳細は実際の `CardView`、強化前後は共通の `CardUpgradePreview`、レリックは実際の定義の名前・説明を表示します。
- 祝福限定カードは取得カテゴリから判定し、専用の枠・光・ラベルを付けます。表示するIDは実際の選択肢に含まれるカードだけです。

## 選択から確定まで

1. 「この祝福の内容を確認」で、選択した祝福をエンジンに保存します。この時点でHP・ゴールド・デッキ・レリックは変更しません。
2. 削除・強化・変化では、エンジンが返した適格カードだけを表示します。対象UIDも選ぶたびに保存します。強化済みなどの除外はエンジンの候補を尊重します。
3. 強化は通常／強化の切り替え、変化は事前に固定された置換先の実カードで確認します。画面側で変化先を推測・抽選しません。
4. 必要な枚数を選び、「祝福を確定して受け取る」で初めて代償と報酬を適用します。確定前なら別の祝福へ切り替えられます。同じ祝福の確認ボタンをもう一度押しても、対象を選び直しません。
5. 結果は保存された受領記録を表示します。HP・最大HP・ゴールドの増減は予定値ではなく実際の適用量です。獲得・削除・強化・変化したカード、獲得レリックを確認できます。
6. 「祝福を胸に、塔を登る」でマップに進みます。再読み込みした場合も、確定前は選択中の対象、確定後は受領結果から再開します。

対象や選択肢はゲーム状態に保存し、強化プレビューの表示切り替えやスクロールは画面だけの状態として扱います。画面はゲーム状態を直接書き換えません。

## 演出と操作

登場時は四つの候補を順に表示し、ホバー・フォーカスで少し浮かせます。初期の演出もスキップできます。受領時は選ばなかった候補を非表示にし、選んだ祝福を中央に表示します。実際の受領記録に応じて、ゴールドの粒、HPの光、カードの移動、レリックの放射光、強化の矢印、変化の軌道、削除の石片、代償の影を使い分けます。通常・高速・短縮・即時を既存設定から受け取り、OSの動きを減らす設定にも対応します。「受領演出をスキップ」を用意し、マップへ進むボタンは演出の終了を待たずに操作できます。

PCでは四つの祝福を横並びにし、スマートフォンでは縦に並べます。長い説明やカードは自然な高さで表示し、本文・数値・ボタンは日本語ゴシック体です。キャラクター名や大きな題字には既存の装飾字体を残しています。

## 検証

`src/tests/blessings-ui.test.ts` の31件で、5職業の初期画面、6キャラクター、四つの選択肢、削除・強化・変化の候補とプレビュー、呪いの実カード、受領した最大HP減少とHPの丸め、レリック、強化結果、限定枠、動きの設定を確認しています。2枚選択中の1枚だけ選んだ状態も、実際のセーブ形式で復元して未確定のまま表示できることを確認します。

開発サーバーで1366×768と390×844の44ケースが成功しました。四つの段階、実際に生成した6人の出会い、保存した会話の復元、文章の収まり、結果の中央配置、8種類の受領エフェクト、初期・受領のスキップ、高速・短縮・即時設定を確認しています。後半のキャラクターも、通常の第1階層クリアと階層移動で生成されたセーブを使用しました。ページ横方向のはみ出しとJavaScriptエラーはありませんでした。全階層の通しプレイ・確定の重複防止は別途ブラウザとエンジンの検証に含めます。

祝福限定カードの戦闘画面は、別の42ブラウザケースでも確認しました。全8枚の通常／強化の表示・限定ラベル・長文、戦闘中だけの強化、スタン、霊体、山札から選ぶ願掛けの保存復元を、1366×768と390×844で検証しています。スタンでは2体のうち対象だけが休み、もう1体は予告どおり攻撃することも確認しました。この42件は開発サーバー上の拳僧を使う代表的な戦闘であり、本番の全職業通しプレイとは分けた結果です。
