# 職業とカード実装の現状

574件の参照データと、実際に取得・使用できるカードの定義を分離しています。説明文の解析結果をそのまま効果として実行する設計ではありません。`classCards.ts` の効果配列を共通エンジンが解決し、実装していない参照カードは取得候補に入りません。

## 参照データと実装の数

- TXTのカード：574件（同一見出し内の二重表記を正規化）。詳細は `card-catalog-audit.md`。
- 今回、通常版と強化版を実行可能にした参照カード：86件。このうち石刃・魂札・聖剣の3件は生成専用です。
- 今回追加した取得可能カード：83種類。拳僧16、影師15、法王15、霊僧15、機巧師16、無色6。
- 生成専用：石刃・魂札・聖剣の3種類。石刃は資料のナイフ、魂札はソウル、聖剣はソヴリン・ブレードに対応します。
- 既存30種類を維持。全体で取得可能113種類、生成専用を含めた使用可能定義116種類。
- 未実装の参照カード：488件。通常の実装待ち407件、元資料の確認が必要81件。実装状態は参照データの状態に実装済みIDを重ねて判定します。

全参照カードで、種別・レアリティはTXTに明記されていません。今回の実装カードは効果から種別を仮設定し、レアリティもIWASON側で仮設定しています。`metadataProvisional: true` を付け、UIでも仮設定として表示します。原作の正式なカード種別・レアリティを確認できたという意味ではありません。

## 明示した暫定ルール

資料にない値やキーワードの基礎ルールを、原作の仕様として補完していません。以下はプレイ可能なIWASON用の暫定ルールで、`classResources` と共通効果処理に分離しています。

- **星**：TXTの数値コストをエナジーとして採用します。資料にない星消費は追加しません。獲得星数とそのターンに得た星数を記録し、「星礼の大合唱」は後者を参照し、獲得0なら攻撃しません。1以上なら獲得数×倍率を基本値とする1ヒットの攻撃で、筋力・脱力・脆弱を適用します。星消費を要求する未解析カードは未実装です。0コスト表記に別の星コストが欠けているかは今後の照合課題です。
- **鍛造**：戦闘中の鍛造値を累積し、聖剣の基本10ダメージに加えます。「岩尊の聖剣顕現」は全札置き場から既存の聖剣を手札へ回収し、なければ生成します。聖剣は通常コスト2・強化後1で保留します。
- **石刃**：0コスト、4ダメージ、廃棄。強化版は6ダメージ。これらはTXTのナイフに記載された数値です。石刃強化パワーと筋力がダメージに加算されます。
- **岩霊（資料のオスティ）**：戦闘開始時はHP0。召喚NでHPをN増やします。敵の攻撃をプレイヤーのブロックで軽減した後、残りを岩霊が肩代わりします。毒・HP消費は肩代わりしません。岩霊の攻撃はHPがあるときのみ発動し、プレイヤーの筋力・脱力・敵の脆弱の補正を受けません。
- **破滅**：敵ターン開始時、毒を処理した後で、破滅が残りHP以上ならブロックを無視して撃破します。通常の毒ダメージとして毎ターン削る処理ではありません。
- **魂札**：生成専用。資料のソウルに対応し、0コスト・2枚ドロー・廃棄、強化後は3枚ドローです。
- **オーブ**：スロット3個。雷はターン終了時3ダメージ／解放時8ダメージ、霜は終了時2ブロック／解放時5ブロック。集中力を加算します。雷の対象はシード付き乱数で決定します。右端が解放対象で、満杯時の追加生成でも右端を解放します。オーブのダメージはプレイヤーの筋力・脱力・敵の脆弱の補正を受けません。
- **保留・エセリアル・天賦**：保留はターン終了時に手札を維持、エセリアルは未使用なら終了時に廃棄、天賦は初期手札に優先して入れます。カード生成先の山札への追加はシード付き処理です。
- **HP消費**：ブロック・岩霊を無視してHPを失い、HPが0になれば直ちに敗北します。

上記は変更可能なゲームルールです。TXTの欠けた文言や数値を書き換えたものではありません。元の通常・強化テキスト、コスト、所属、行番号、疑義は参照データに保持しています。

## 出現と互換性

新規ゲームは職業選択後に開始します。戦闘報酬は選択職業だけです。ショップは職業カードと無色カード、イベントは指定されたプールを使います。初期攻撃・防御は `rewardEligible: false`、生成専用は `tokenOnly: true` によって除外します。特別イベントに限って他職業を許可する設定を用意しています。

職業IDのない既存セーブは旧方式のランとして引き継ぎます。旧30種類のカードIDと旧初期デッキを維持し、旧ランの抽選も `LEGACY_CARD_IDS` に固定します。生成したカードは永続デッキへ混ぜず、戦闘専用の生成カード台帳で管理します。

## 未実装の理由と次の単位

488件は効果がないまま取得できるようにしていません。主な未対応処理は、一時コスト変更・カード変化・自動プレイ・リプレイ・永続成長・複数プレイヤーへの効果・未対応オーブ・追加キーワード・複合条件付きの誘発処理です。資料でコスト「ー」、効果「ー」、数値や単位の抜けがあるものは、別途確認が必要です。

次は、カードの選択・移動を共通化した仕組みを使って回収や変化を増やし、誘発条件を拡張する単位で進められます。追加ごとに通常・強化・複雑な組み合わせ・セーブ復元を検証してから取得プールへ公開します。
