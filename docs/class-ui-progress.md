## 変更しない戦闘ルール

オーブは3枠で、生成は末尾へ追加、解放は右端を取り出す。自動発動は配列順。雷は3/8、霜は2/5に集中力を足して0以上へ丸める。星は獲得・参照用で、星の消費コストは存在しない。星連携攻撃は当ターンの獲得数を参照する。

岩霊は通常攻撃をブロックで防ぎきれなかった分だけHPで肩代わりする。毒・HP消費は肩代わりしない。全体攻撃は岩霊とプレイヤーそれぞれに当たる。岩霊は専用カードで攻撃し、自動攻撃はしない。破滅は敵のターン開始時、毒の処理後のHP以上なら発動する。

## 再開方法

既存の変更を破棄せず `git status --short` と本記録を確認する。`npm test`、`npm run build` を使う。新規のリソース説明はエンジンのセレクターを参照し、UIから乱数やゲーム状態を更新しない。演出用メタデータは保存に追加しない。詳細は実装後の `class-combat-ui.md`、`class-ui-validation.md` を参照する。
