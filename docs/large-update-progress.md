## 再開時の確認

`git status --short` で作業を確認し、既存変更を破棄しない。担当別の詳細は `enemy-expansion.md`、`relic-expansion.md`、`event-expansion.md`、`expansion-validation.md` に記録する。新規ファイルが未作成なら、その担当はまだ進行中。

戦闘ロジックの変更はエンジン内に置く。保存バージョンは戦闘v1・探索v2を維持し、追加状態は省略可能にする。イベントの確定結果は探索状態へ保存し、UIの表示だけで抽選しない。休憩所のプレビューはコピーを表示し、確定時にだけ既存アクションを呼ぶ。

検証コマンドは `npm test` と `npm run build`。GitHub Pagesのbaseとワークフローを維持し、強制プッシュを行わない。公開はmain反映時に自動実行し、最新の成否は [GitHub Actions](https://github.com/sunnytruck/spyier/actions/workflows/pages.yml) で確認する。

敵は計21種、レリックは計30種、イベントは計18種。追加の呪い「石心の迷い」はイベントの対価としてのみ取得し、通常報酬や強化候補に混入させない。溶岩の小瓶の説明を実際の計算に合わせて修正し、戦闘計算は変えていない。
