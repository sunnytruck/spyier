# 拡張カードと選択操作のUI検証

今回追加されたカードと効果処理について、既存の見た目と職業HUDを維持したまま動作することを検証しました。テスト用データは実際のカード定義、戦闘エンジン、セーブ検証処理から作成しています。

## 自動テスト

`src/tests/roguelike-ui.test.ts` の23件が成功しました。

- 手札／捨て札から山札の上に戻す選択、および捨て札から手札へ戻す選択で、実際の候補と一致したカードを表示。
- `sourceZone` がない旧セーブの、手札から捨てる選択を維持。
- 選択内容を確定する前の描画では状態を変更しない。
- 負の筋力を数値と下向きのアイコンで表示。
- 通常／強化のカード名・コスト・効果文・天賦・保留・廃棄の変更を実データと照合。
- 新しい保存済みショップ価格と、旧セーブの一律55G表示を、実際の購入金額と照合。

SSRでは手札のポインター用Portalを省略しています。実際の操作は以下のブラウザ検証で補っています。

## ブラウザ検証

ChromiumのVite開発サーバーで、PC相当1366×768とタッチ端末相当390×844を検証し、計78ケースが成功しました。ブラウザのJavaScriptエラーはありませんでした。

すべてのケースでページ横方向のはみ出しを確認しました。カードの説明文・見出し・戦闘中の現在値は、表示領域とスクロール寸法を照合して切り抜きがないことを確認しています。報酬選択・ショップ購入・強化確定は実際のUIから操作しています。

## 範囲と残る確認

- 全104枚の戦闘効果の検証は、別途カードエンジンのテストが担当します。このブラウザ検証は各所属の長文カードと代表的な操作を対象とし、104枚すべての全画面表示を網羅するものではありません。
- 画面幅とタッチ操作はブラウザによる模擬環境です。実機固有の日本語フォント・ブラウザ差異は継続確認の対象です。
- 上記78ケースは開発サーバーの結果です。本番ビルド・通しプレイ・自動公開の確認は、リリース時の検証に含めます。
