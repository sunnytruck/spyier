# 職業リソース表示と既存の戦闘ルール

この更新は戦闘ルールを変更せず、`src/engine/combat/resourceView.ts` の読み取り専用セレクターを介して既存状態を表示します。表示用の計算は戦闘状態や乱数を変更せず、演出イベントもセーブには保存しません。

## 岩核の機巧師

- スロットは既存の3個。空スロットも表示します。
- 配列の左から右へ生成順に並べ、自動発動も左から右です。
- 解放対象は既存実装どおり**右端**です。満杯で生成した場合も右端を解放して同じ位置に新しいオーブが入ります。
- 2回解放は右端の同じオーブを2回発動し、そのオーブを1個だけ除去します。
- 雷：自動3、解放8に集中力を加算。霜：自動2、解放5に集中力を加算。0未満は0です。
- 雷は生存敵からシード付き乱数で選択します。プレイヤーの選択対象、筋力・弱体・敵の脆弱は参照しません。敵のブロックは有効です。
- 一時集中力の解除はターン終了のオーブ自動発動**後**です。
- 実処理と表示は `orbEffectValue`、`orbSlotCount`、`nextOrbEvokeIndex` を共用します。

## 黄泉渡りの霊僧

- 岩霊はHPを持つ護衛です。召喚効果はHPを加算します。
- 通常攻撃はプレイヤーのブロックを先に消費し、残りを岩霊HPで肩代わりします。余剰だけ本体に命中します。
- 全体攻撃は岩霊と本体に個別命中し、岩霊は本体を肩代わりしません。毒・カードの直接HP消費も肩代わりしません。
- 岩霊は命令カードを使ったときだけ攻撃し、ターン終了の自動攻撃はありません。カード定義が指定した場合だけ現在HPを攻撃値へ加算します。
- 岩霊攻撃は筋力・弱体・脆弱の補正を受けず、敵ブロックは有効です。
- 敵ターン開始は毒のダメージを先に解決し、残りHPが破滅値以下なら破滅が発動します。

## 星詠みの法王

- 累計の星と「このターンに獲得した星」は別値です。
- 現行カードは星をコストとして消費しません。星を参照する攻撃は当ターン獲得数を参照します。獲得数0なら筋力があっても不発です。
- 次のプレイヤーターン開始時に当ターン獲得数を0へ戻します。累計星と鍛造は戦闘中維持します。
- 聖剣はカード定義の通常・強化コストを使い、基礎攻撃値へ現在の鍛造値を加算した後、通常の攻撃補正を適用します。
- HUDの現在威力は現在状態に対する値です。カード使用時に発動するレリックなどで変動する場合があり、カード詳細の使用時情報も参照してください。

## 岩砕の拳僧・静刃の影師

- HP消費はカード効果の `loseHp` を参照し、通常の敵攻撃と区別します。ブロックや岩霊では防げません。
- 石刃の追加威力は実際の `knifeDamage` パワーを参照します。筋力・弱体・脆弱は通常攻撃どおり適用します。
- 毒の次回ダメージは現在の毒値に基づきHPまでを表示します。ブロックを無視し、発動後に毒が1減ります。プレイヤーがカードを使って毒やHPを変えれば予測も更新されます。

## 演出データ

オーブの演出には位置 `orbIndex`、発動種別 `orbMode`、操作 `resourceAction` を付与します。攻撃元は `orb-0` などのスロット、岩霊攻撃元は `osty` です。数値0の霜も自動発動の位置を識別できますが、ブロックを得たという偽の効果は出しません。解放・生成・発動の情報は戦闘イベントだけに置き、既存セーブの形や乱数状態を変更しません。
