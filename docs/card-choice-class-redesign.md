# カード選択・職業選択の再設計（2026-10-21）

開始時点は `442e77f`、作業ツリーと `origin/main` は一致し、未コミット変更はなかった。前回完成したマップ・祝福確認の祭壇・戦闘演出は維持した。今回の対象はカード選択／確認表示と職業選択だけで、エンジン、カード／職業データ、抽選、保存形式は変更していない。

## カードの選択と確認

新しい `ChoiceCard.tsx` と `card-choices.css` を選択・確認表示に使用する。イラスト付きの `CardView`、戦闘の扇状手札、ホバー、ドラッグ、カード移動演出はそのまま残す。

- コスト・名前・種別を暗緑の見出しに、全文の効果を明るい石板色に濃いゴシック体で表示。イラスト領域をなくし、幅と高さを選択一覧に合わせる。長文は省略せず折り返す。
- カード本体が1つのネイティブbuttonで、マウス・タップ・Enter／Spaceで選択。大きな個別選択ボタンを廃止し、選択中は発光・持ち上がり・チェック・`aria-pressed` で示す。
- 強化切替は本体buttonの外に独立した小さいbuttonとして置く。押してもカードは選択されず、定義の通常／強化コスト・説明・キーワードを表示するだけ。実際のカードは変更しない。強化対象一覧の全体チェックボックスも維持する。
- 使用不能な呪い、エナジー不足のカードも、既存ルールで選択可能なら捨て札／削除の対象にできる。戦闘の「使用可能」判定を選択UIへ流用しない。
- 元の対象一覧・選択上限・確定条件・キャンセル可否を維持。戦闘の必須選択は閉じられず、画面下の1つの確定ボタンで継続する。0枚を許可するレリックの選択も維持する。

| 対象 | 維持した操作 |
| --- | --- |
| 戦闘中の捨て札・廃棄・山札／捨て札から回収・山札上へ戻す | 指定枚数を選択して確定。対象pileと効果の再開処理を維持 |
| 休憩所の強化 | 全カードの強化プレビュー、カード選択、強化前後の確認、確定／キャンセル |
| ショップの削除 | 元の価格・枚数制限を表示し、カード選択時に削除。閉じる操作を維持 |
| 祝福の削除・変化・強化 | 保存済みの選択UIDと候補を使い、祭壇で確定するまで効果を適用しない |
| レリック取得時の削除・強化・変化・複製・カード獲得 | 保存可能な中間選択、指定枚数、確定と取得結果を維持 |
| カード報酬 | カード全体のクリックで1枚取得、スキップ可能 |
| デッキ・山札・捨て札・廃棄札の確認 | 読みやすい表示と任意の強化プレビュー。カード使用や変更は行わない |

共通の強化確認 `CardUpgradePreview` も新しい読みやすい面を使う。一般ショップの購入表示、図鑑、戦闘の拡大カード、祝福の獲得イラストは今回の再設計に含めず維持した。

## 職業の選択

`ClassSelectionScreen.tsx` と新しい `class-cast.css` で、5枚の情報パネルと常設初期カード一覧を廃止した。

- 左を大きい既存 `RockDeity` の立ち絵と神殿・紋章の舞台、右を職業名・特徴・HP・初期レリック・デッキ要約と開始操作にする。
- 拳・石刃・星・魂・回路を描いたオリジナルSVGの5紋章で職業を切り替える。職業ごとに色・背景・装備・立ち絵が変わり、選択中の紋章が発光する。
- 初期デッキは枚数と攻撃／スキル数を簡潔に表示。詳細buttonから別のModalでカードと強化前後を確認できる。
- 初期HP・レリック・デッキ・職業ID・開始処理は既存データとcallbackを使用する。5職業の性能は変更しない。
- 1366×768では基本操作を1画面に配置。狭い画面は立ち絵の下に紋章と詳細を配置し、必要なスクロールは画面内に収める。設定とOSのアニメーション軽減にも対応する。
